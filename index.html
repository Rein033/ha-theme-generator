What can HA Theme Generator do?

    
Design a Home Assistant theme with colour pickers and presets, preview it live on a dashboard in light and dark mode, and copy the theme YAML.

    
  • Presets to start from: Default, Nord, Dracula, Ocean, Forest, Sunset, Graphite and Soft
  • Separate light and dark mode in one theme (modes:), or make dark from light in one click
  • Card radius, border, shadow and font
  • Live preview of a dashboard with sidebar, tiles and cards
  • Contrast check for text (WCAG) so your theme stays readable
  • Paste an existing theme to edit it; share a theme with a link

  

  
Frequently asked questions
How do I install a Home Assistant theme?
Add frontend: themes: !include_dir_merge_named themes to configuration.yaml, save the theme YAML as /config/themes/name.yaml, run Reload themes in Developer tools and pick the theme in your profile.
Can one theme have a light and a dark mode?
Yes. With Include both light and dark the theme uses modes:, and Home Assistant switches automatically with your device's light or dark setting.
Can I edit an existing theme?
Yes. Click Paste theme, paste your theme YAML and it loads into the editor, including both modes.
Why does the contrast check matter?
Text needs enough contrast with the card background to stay readable. The check uses the WCAG guideline: 4.5:1 or higher is good for normal text.
