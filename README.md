# HA Theme Generator

[![Buy me a coffee](https://img.shields.io/badge/Buy%20me%20a%20coffee-rein033-FFDD00?logo=buymeacoffee&logoColor=black)](https://buymeacoffee.com/rein033)

Design a Home Assistant theme with colour pickers and presets, preview it live on a dashboard in light and dark mode, and copy the theme YAML.

**Use it:** [uselesssite.nl/ha-theme-generator](https://uselesssite.nl/ha-theme-generator/)

- Presets to start from: Default, Nord, Dracula, Ocean, Forest, Sunset, Graphite and Soft
- Separate light and dark mode in one theme (`modes:`), or make dark from light in one click
- Card radius, border, shadow and font
- Live preview of a dashboard with sidebar, tiles and cards
- Contrast check for text (WCAG) so your theme stays readable
- Paste an existing theme to edit it; share a theme with a link

Everything runs in your browser, nothing is sent anywhere.

Part of the free, open-source tools at [uselesssite.nl/tools](https://uselesssite.nl/tools/).

## Development

Plain HTML, CSS and JavaScript, no build step. Open `index.html` through any static web server.
`base.css` and `base.js` are shared with the other tools; the tool itself lives in `app.js` and `style.css`.
